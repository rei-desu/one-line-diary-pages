プライバシーポリシー

1行日記
最終更新日: 2026年10月12日

本ポリシーは、日本の App Store で提供するアプリ「1行日記」（以下「本アプリ」）における情報の取り扱いを定めるものです。

運営者: ReiKomatsuzaki
連絡先: onelinediary0928@gmail.com

取得する情報と利用目的

日記の本文は、その端末の中に保存します。iCloud にサインインしているときは、同じ本文をその利用者の iCloud（CloudKit のプライベートデータベース）にも保存し、その利用者の端末間で同期します。サインインしていないとき、または iCloud の使用が制限されているときは、その端末の中だけに残ります。運営者のサーバには送信せず、運営者は本文を閲覧できません。

振り返りの表示、振り返りの間隔、通知のオンオフと時刻、起動時ロックのオンオフは、その端末の中だけに保存します。iCloud には同期しません。目的は、その端末での表示と通知、起動時ロックです。

広告の非表示と起動時ロックは、Apple の App Store を通じた買い切りです。代金の支払いは Apple が処理します。運営者はカード番号を受け取りません。端末では、購入済みかどうかを確認します。起動時ロックの行から購入を始めたときは、その時点の取引 ID もその端末に保存します。この ID は、その購入が検証されたとき、キャンセル、失敗、または未検証になったとき、広告の行から購入を始めたとき、復元を始めたときに消します。保留のままアプリが終了しても残します。

購入の有無にかかわらず、アプリの起動時に Google AdMob の SDK を初期化します。この通信で、Google が IP アドレスや端末に関する情報を取得する場合があります。バナー広告を読み込むのは、買い切りを購入していないときのうち、振り返りを表示しているときと、設定を表示していて有料サービス画面を開いていないときです。今日の1行の画面では読み込みません。広告はパーソナライズしません。追跡の許諾ダイアログは表示しません。日記の本文は広告のリクエストに含めません。

リマインダーは、端末の中で予約するローカル通知です。通知の内容を運営者のサーバへ送信しません。

購入済みで起動時ロックをオンにしたとき、その端末の Face ID、Touch ID、またはパスコードで画面をロックします。生体情報は端末の中で照合され、運営者には送信されません。

第三者

運営者は、日記の本文を運営者のサーバや広告のリクエストへ送りません。iCloud にサインインしているとき、本文は Apple の iCloud に保存されます。

  • Apple: サインイン中の日記本文の iCloud への保存、App Store での配信、買い切りの決済
  • Google: 起動時の SDK の初期化と、上記の条件でのバナーの配信。Google は、受け取った情報を Google の広告配信の目的で使うことがあります
  • その他の広告ネットワーク: バナーを表示するとき、Apple が広告の成果計測のためポストバックを送ることがあります。日記の本文は含まれません

Apple と Google は、受け取った情報を各社のプライバシーポリシーに従って扱います。その利用目的は各社のポリシーに従い、運営者の目的には限定されません。各社は、受け取る情報について、本ポリシーと同等の保護を行います。

Google のプライバシーポリシーは https://policies.google.com/privacy です。

広告に関する情報は、Google により日本国外で処理される場合があります。日記の本文を、運営者の国外サーバへ送ることはありません。

保持と削除

日記の本文は、利用者がその日の記録を削除するまで、保存された場所に残ります。iCloud に同期済みのコピーは、アプリを削除したあとも、その利用者の Apple ID の iCloud に残ります。同期されていない本文は、アプリを削除するとその端末から消え、iCloud には残りません。運営者は本文のコピーを持たないため、運営者の側で本文を削除することはできません。

端末内の設定は、アプリを削除すると消えます。

広告のために Google が取得した情報の保持と削除は、Google のプライバシーポリシーに従います。

開示などの請求

その日の1行は、振り返りでその月を開けるときに削除できます。端末の今日より先の月にある記録は、振り返りからその月を開けないため、その月が今日の月以前になるまで、振り返りからは削除できません。今日の1行は、本文を空にして今日の画面を離れるか、アプリを背面に回すと削除されます。

運営者が保有する情報についての開示、訂正、追加、削除、利用停止の請求は、上記のメールアドレスへ連絡してください。運営者は日記の本文を保有していません。広告のために Google が保有する情報は、Google に対して手続きしてください。

このページ

このウェブサイトは、本ポリシーとサポートの案内を掲載します。ページ自体では、アクセス解析やクッキーによる情報の取得をしません。

改定

本ポリシーを変更したときは、このページに新しい内容を掲載し、最終更新日を改めます。
